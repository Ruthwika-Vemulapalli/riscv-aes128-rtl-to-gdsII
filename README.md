# riscv-aes128-rtl-to-gdsII
Implementation of a 32-bit RV32I RISC-V Processor integrated with an AES-128 cryptographic accelerator, covering the complete RTL-to-GDSII ASIC design flow including synthesis, floorplanning, placement, CTS, routing, STA, DRC/LVS, and timing closure using Cadence Genus, Innovus, and Tempus. Achieved 100 MHz operation with positive timing closure.
